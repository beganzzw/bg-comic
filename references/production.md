# 生图、验收与交付（阶段5—6才读取）

## 样图与整套

先检查风格、角色方案、分镜对白、页数及用户生图授权。默认选有代表性的一页作为样图，包含人物动作、中文与气泡。生成并检查后交付用户选择；未获得样图确认时不自动批量扩展。用户已确认同一作品样图，或明确授权一次完成、无需逐步确认时直接在授权范围内制作整套，但仍先在内部检查首图，不把明显错误扩散到其他页。

读取 `image-capabilities.md`，发现并适配当前 Agent 自带或已配置的图片能力与默认模型，不绑定服务名、模型ID或本机程序。按实际参数结构映射需求。传入独立完整提示词，区分风格参考与身份参考。每页固定系列名、当前页/总页，禁止图外脚注和额外文字；允许用户另行要求。风格参考不得覆盖所选格数，界面标签纳入文字白名单。

异步ID返回后使用当前服务指定的等待、查询或完成通知机制跟进同一任务至完成或明确失败；要求等通知的后台任务不轮询，不在仅提交后声称完成。跟进过程中给简短进展，不重复提交仍在运行的任务。EOF仅表示连接提前结束，查不到ID不证明服务重启。先查指定文件；连续失败可用一次无参考图测试定位，但不要推断未经证明的根因。按用户授权降级时说明IP一致性损失。

## 视觉验收

逐张实际读取图片，核对文字、格数、页码、角色姿态、气泡尾巴、工具窗口数量、重复标签、意外具体模型名称。按已选风格检查色彩，不向彩色预设施加黑白禁色要求。无法看清时放大局部，不将图片能打开视为验收通过。

改错优先处理受影响的页，保留已有合格页和原文件。裁切先读取真实像素尺寸及分镜边界，不把缩略图坐标直接用于原图；修改后检查下排对白和边框。RGBA图片按所选纸色合成背景。禁止以平滑矢量或头像裁贴冒充手稿重新绘制。

封面另行构图，按实际用途及用户尺寸制作。900×383横幅与3:2画布是不同要求，不宣称一种比例适配所有入口。不得把竖版拉伸成横幅。缩略图需保持标题、角色可辨。

## 成品组装

默认标题加连续漫画及必要来源链接，不额外复述漫画。真实截图仅用户要求或证据确实必要时补充，优先放整套漫画之后。用户删除的提示或脚注不得再次恢复。

调用 scripts/build_preview.py --title "标题" --images <按序绝对路径...> --output-dir <工作区outputs下的新目录>。脚本生成独立预览及ZIP，使用新目录保留旧版本。呈现用户需要看的结果文件，并说明尚未解决的偏差。

发布是独立动作，必须有明确授权。草稿与公开发布分开报告。发布前查目标唯一性、图片、行内排版及封面，回读验证；权限拒绝后不重复同一请求。不要在技能内保存凭证或固定草稿ID。
