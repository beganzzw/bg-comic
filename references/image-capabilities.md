# 当前 Agent 生图能力适配

仅在即将生成图片或排查生图失败时读取。技能定义内容与质量要求，不提供固定服务、模型ID、API地址、密钥、本机程序路径或通用伪API。

## 发现和选择

1. 遵守宿主环境的工具使用规则，检查当前 Agent 已暴露的图片生成/编辑能力，必要时通过其工具发现机制加载参数说明。
2. 用户明确指定服务或模型时优先选择该项，但必须确实可用且参数支持。不可用时如实说明，不能偷偷换成别的模型并声称照做。
3. 未指定时优先使用当前 Agent 内置或已配置的图片生成能力及其默认模型。不要自动连接个人本机服务、读取本机MCP凭证或启动本地程序。
4. 已有多个可用能力时，优先匹配任务需要的参考图、编辑、画幅和文字渲染能力。常规选择可自主完成；若涉及新的付费授权、外部账号或关键效果变化，说明并按环境规则处理。
5. 没有可用生成能力时，简短说明当前Agent不能直接生图，立即按下方“提示词交付分支”给出可复制的提示词；不要只说不支持、要求安装连接器或询问是否需要提示词后就结束。不虚构工具，不将聊天模型等同图片模型。

## 提示词交付分支（无生图能力时默认执行）

在已确认的主题、大纲、对白、风格与角色方案上直接生成提示词，不要求用户为获取文字再确认一次。把交付物明确标为“生图提示词”，不要称为成图或完成发布。

- 首先简述实际限制：当前环境未提供图片生成能力。紧接着交付提示词，不把安装服务作为前置要求。
- 逐页提供独立可复制代码块。每页必须完整包含画幅/目标尺寸、格数/布局、所选风格、角色辨识点、每格动作、说话者与逐字对白、气泡指向、页码、允许文字及负向约束。不要仅给通用模板，也不要要求用户自行拼接“同上风格”。
- 附上参考图使用说明：哪张锁定角色、哪张参考笔触。提醒用户在实际生图环境上传对应素材；当前Agent已读过图片不代表另一工具已收到。未知目标平台时使用平台无关自然语言，不伪造模型参数、文件ID或平台专属语法。
- 有明确封面需求时另给完整封面提示词，与漫画页区分，说明比例、安全留白和精确标题。没有封面需求不擅自增加任务。
- 延续渐进阶段：尚未确认风格/IP/对白时先推进当前可完成的阶段；可先给通用角色文字草案并标注待补项，但不能将缺失资料编成确定设定。缺图不阻止提供文本。
- 最后只补简短验收项，例如格数、页码、工具名称数量、中文完整与气泡归属。用户把成图带回后可继续检查和排版。
- 用户只要提示词时聊天中直接给出；用户要文件或内容很长时同时保存为工作区文本文件并呈现，不要求外部账号或网络授权。

## 参数映射（每次依据真实schema）

先形成与服务无关的需求：准确对白、画面、风格、身份参考、目标比例/尺寸、张数、交付位置。再映射到实际工具：

- 提示词：使用工具实际支持的文本参数。
- 参考图：确认支持几张、图片用途与传入格式（本地文件、附件、URL、文件ID等）。只使用可访问且工具接受的引用；路径不兼容时走宿主提供的上传或附件方式，不把本地路径冒充公网地址。
- 尺寸：只传支持的枚举、像素或比例。目标尺寸不可用时采用接近比例生成，再补边或合理裁切，不拉伸人物；验收最终尺寸。
- 模型：工具未暴露模型选择字段时使用工具默认，不自行添加model字段。已暴露时只用真实可用选项；用户未指定则通常省略。
- 质量/张数/种子/背景等：只有参数实际支持才传入，不依赖固定quality值或seed维持一致性。
- 输出：接受真实返回的文件、附件或URL；工具不支持指定目录时，按宿主能力保存成品并记录实际路径。

对话上下文中的图片不保证已自动传给生图工具。调用前确认角色参考实际附带，不能仅写“参考上传图片”却不传素材。

## 能力不足时

缺少参考图能力但用户需要准确个人IP时，先说明限制并提供可行路径，不能无声改为文字近似。用户授权近似时记录一致性限制。中文不稳定可生成无字画面后排版，但不得把这种方案声称为精确局部编辑；用户明确纯生成要求优先遵循。不具备编辑能力时不能假称能保留原图像素进行局部修改。

## 返回与异步生命周期

- 同步文件/附件：保存或定位真实产物，读取并验收。
- 远程URL：按工具要求下载或展示；注意有效期，不展示签名凭证。
- 异步ID：使用该服务指定的查询/等待方式。明确要求轮询的服务按其节奏查询；宿主后台任务要求等通知时等待通知，不自行轮询。保持同一ID，不把任务ID跨服务使用。
- 处理中：保持进展说明，不重复提交同一任务；不要声称已完成。
- 失败：仅报告已观测事实，不把EOF归因成必然上传失败或服务重启。检查指定产物是否已存在，避免重复生成与费用。

当前生图服务与默认模型由宿主管理。本技能不修改宿主模型设置，不将某次测试服务设为后续机器的默认依赖。

## 适配验收场景

- 仅有宿主内置生成工具 → 用其默认模型，不寻找本地服务。
- 有参考图但工具仅支持文字 → 明确限制，不假称已附参考。
- 目标900×383但工具只接受固定尺寸 → 使用接近横幅的支持尺寸再导出，不传非法值。
- 服务返回任务ID → 按该服务实际机制收取产物，不套用其他服务查询接口。
- 用户只要提示词 → 不发现账号、不发起生成。
