# 可选视觉风格

## 选择与覆盖规则

仅在进入视觉设计阶段时读取本文件，不在主题和大纲阶段设置风格门槛。不自动选择默认画风。准备设计画面时确定风格：用户已指定或同一作品已确认时直接沿用；未指定时推荐一种并说明视觉特点和适配理由，必要时给一至两种备选，等用户选择后再进入依赖画风的视觉创作；不阻断主题、大纲或通用对白讨论。明确授权自主选型时可选择并说明后继续。六种仅为预设，支持自定义描述、参考图及预设修改，不要求用户只能在列表内选。只说换个风格时先推荐并等待选择，不擅自付费生成全部。把style与format分开：style决定线条、配色和质感；format可为四格、六格、单图封面、概念图或流程图，不能选了白板风就自动把个人故事变成课件。

整篇固定一种画风、角色比例和色板。风格对比样张使用相同对白、场景、画幅、角色与信息量，仅改变视觉表现；明确要求生图才执行。彩色风格覆盖黑白母版中的禁彩色、禁灰阶规定，不得把互斥条款同时拼入提示词。

公开版在 `examples/` 目录下提供了 6 种风格及封面的实测样例（见 `examples/style-*.png` 与 `examples/comic-*.png`），仅作视觉效果与风格差异参考，不作为技能内置角色。创作时使用本任务用户提供并确认的参考图约束角色身份，并声明不要沿用设定板的画风。未提供其他风格样图时使用下列文字母版。

统一保留本任务用户提供并确认的角色辨识点，不默认采用边牧。以下各预设中的边牧、耳麦、领巾和暖金蓝色仅为历史案例：组装提示词时必须替换为当前角色对应特征与配色；用户选择无IP时删除这些要求。风格变化允许线条与身体比例变化，不丢已确认辨识点。文字始终清晰，潦草仅应用于画面。

## 1. 黑白手稿 / ink-sketch（预设）

适用：个人经历、自嘲吐槽、技术生活漫画。

提示词母版：米白纸底、黑墨线，断笔、不闭合轮廓、略粗糙的手绘圆角分镜，扁平二维，大量留白。用轮廓和少量黑色剪影塑造角色，中文端正清晰。

负向约束：不要彩色、灰阶大面积填充、数字渐变、光滑矢量轮廓、写实光影。

验收：确认对比鲜明、阅读顺序清楚、角色动作不同；不把文字也做成难读的涂写。

## 2. 潦草涂鸦 / Scribble / scribble

适用：荒诞自嘲、尴尬瞬间、轻松短篇、夸张封面。

提示词母版：像随手用马克笔或粗蜡笔画出的稚拙涂鸦，歪扭轮廓、少量复描、夸张但可识别的动作，物件比例故意不齐，纸面留白。默认黑线配米白底，可按用户要求增加一种点缀色。保持耳麦、领巾、立耳和脸纹。中文排版清晰整齐，与歪扭插画形成反差。

负向约束：不要精致描边、3D、摄影、密集线团遮住角色、乱码或故意错字；不要因潦草而额外生成肢体和窗口。

验收：粗糙有趣但事件可辨；角色和道具数量准确；不过度损害IP一致性。

## 3. 治愈手绘 / healing

适用：工作小烦恼、个人日常、温和的反思与陪伴故事。

提示词母版：暖白纸底，柔和铅笔或细墨线，克制的低饱和奶油色、鼠尾草绿与浅蓝，局部淡彩纸感。保留暖金边牧与蓝色耳麦领巾，生活化姿态和自然小表情，简单室内道具、宽松分镜。对白保持原来的笑点，不额外编造治愈结论。

负向约束：不要全图高饱和色、甜腻滤镜、复杂水彩背景、煽情光晕、幼儿化全部台词。

验收：字与背景对比充分；温和但仍有动作与情节；允许淡彩和柔和明暗，不套用黑白禁止条款。

## 4. 极简图解 / 小豆人概念图解 / minimal-diagram

适用：解释一个概念、比较两种处理方式、文章中的单张补图。

提示词母版：白色或米白纸底，极简手绘线条、豆形身体和小圆头，将角色简化但保留边牧耳朵、耳麦、领巾与脸纹。用极少物件、必要箭头和短标签讲清一个问题，默认黑线加一种浅色强调。每个箭头有明确起点和终点，分组留白充分。

负向约束：不要把人物替换成失去辨识度的通用小豆人，不增加无关装饰、密集术语、复杂仪表盘，不将漫画对白自动改为功能清单。

验收：读者能复述核心关系；若用户要求故事，仍保留人物行动，不自动转换成教学流程。

## 5. 活力手绘 / vibrant

适用：醒目封面、工具尝鲜、短篇趣事、团队分享。

提示词母版：暖白纸底，粗黑手绘线，手工剪纸感的少量平涂色块，夸张动作和明确视觉重心。固定两至三种强调色，例如暖金、蓝和珊瑚橙；背景保持清淡。标题醒目，人物五官与配饰保持一致，各格色彩用途相同。

负向约束：不要彩虹色混用、霓虹渐变、满页色块和装饰符号、矢量商业图标感，不用颜色掩盖文字拥挤。

验收：缩略图仍有单一焦点；整篇配色固定、文字清晰；幽默不靠过度大叫表情。

## 6. 白板手绘 / Excalidraw风 / whiteboard

适用：教程补图、系统关系、流程与逻辑说明。

提示词母版：白底，略微抖动的黑色细线框、手绘箭头、便签与简笔图标，少量浅黄或浅蓝强调，布局疏朗。用简化边牧作引导角色但不抢占图示空间。中文使用清楚易读的字体。只画用户提供且有依据的关系。

负向约束：不要3D、写实材质、复杂透视、大段文字；不把所有节点连起来，不生成不存在的关系；没有使用真实白板工具时不要声称输出可编辑的Excalidraw工程。

验收：检查连线方向、标签和节点数量；白板画风不等于产品功能介绍，故事场景仍按已确认大纲执行。

## 组装顺序

依次合并：本页事实与画面动作 → 角色身份 → 所选风格母版与其专属负向约束 → 画幅和格数 → 精确对白与文字白名单 → 页码及数量限制。

在执行前检查是否同时出现“允许淡彩”和“严禁任何彩色”等冲突；只保留当前风格有效要求。切换风格不应改变台词、主张、事实边界或自动授权发布。
